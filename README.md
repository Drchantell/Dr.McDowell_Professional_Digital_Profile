# Dr. Chantell McDowell Professional Portfolio

This is the complete source-code folder for the professional portfolio website.

## Main files

- `index.html` — Home page
- `about.html` — About / My Story / Publications
- `technology.html` — Technology and makerspace skills
- `leadership.html` — Leadership and professional experience
- `resume.html` — Resume page
- `contact.html` — Contact page
- `style.css` — Main website styling
- `script.js` — JavaScript / interactions
- `assets/` — Images, resume files, book cover, MakeHERspace logo, and other media

## Open in VS Code

1. Download and unzip the project folder.
2. Open Visual Studio Code.
3. Choose **File > Open Folder**.
4. Select the `Dr_Chantell_McDowell_VSCode_Portfolio` folder.
5. Open `index.html`.

## View the website

### Easiest method: Live Server

1. In VS Code, install the **Live Server** extension.
2. Right-click `index.html`.
3. Choose **Open with Live Server**.

The site will open in your browser.

## Important

Keep the `assets` folder in the same project folder. The website uses relative paths such as:

`assets/images/...`

Moving individual HTML files outside this folder will break images and other assets.

## Publishing

This project is also structured so `index.html` can be uploaded to the root of a GoDaddy `public_html` folder with the other HTML, CSS, JS, and `assets` files beside it.
