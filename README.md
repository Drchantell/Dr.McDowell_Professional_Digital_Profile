## How to View It on Your Mac in VS Code

1. Download and unzip this portfolio.
2. Open VS Code.
3. Choose **File → Open Folder**.
4. Select `Dr_Chantell_McDowell_Sophisticated_Portfolio`.
5. Open `index.html`.
6. If you have the Live Server extension, right-click `index.html`.
7. Choose **Open with Live Server**.

If you do not have Live Server:
1. Open Extensions in VS Code.
2. Search for `Live Server`.
3. Install **Live Server by Ritwick Dey**.
4. Return to `index.html` and click **Go Live**.

## Best Place to Publish

### Recommended: GitHub Pages
This is the best first choice because employers can immediately connect your
portfolio with your GitHub development work.

1. Create a new GitHub repository named something like `professional-portfolio`.
2. Upload all files and folders from this package.
3. In GitHub, open the repository.
4. Select **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose `main` and `/root`.
7. Save.
8. GitHub will provide your live website address.

### Also Excellent: Netlify
Netlify is simple and polished for static websites. Connect the GitHub repository
and it will deploy automatically whenever you push changes.

### Future Upgrade: Vercel
When you rebuild this portfolio with React or Next.js, Vercel is an excellent
long-term hosting choice.
